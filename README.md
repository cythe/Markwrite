# MarkWrite

一个用 C# / WPF + WebView2 实现的 Typora 风格 Markdown 编辑器：编辑区是**块级所见即所得**（光标所在的块显示 Markdown 源码，离开后立刻渲染成排版结果），左右两侧提供文件树与大纲，支持多标签、表格、公式、Mermaid 图表和导出。

## 运行

直接运行可执行文件：

```
bin\Release\net10.0-windows\MarkWrite.exe
```

也可以带文件打开（等同双击关联）：

```
MarkWrite.exe 某文档.md
```

前提是系统已安装 **Microsoft Edge WebView2 Runtime**（Win10/11 通常自带）。

## 功能

**编辑**

- 块级双态渲染：光标进入哪一块，哪一块变成可编辑的 Markdown 源码；光标离开即渲染
- 支持标题（1–6 级）、段落、引用、有序/无序/嵌套列表、任务清单、分割线
- 行内：粗体、斜体、粗斜体、删除线、高亮、行内代码、链接、图片、行内公式
- 围栏代码块（```` ``` ```` 与 `~~~`），带语法高亮，支持 C#、JS、Python 等常见语言
- 表格：按 `|` 切列，识别 `:---:` 对齐；点击表格进入源码即可逐格修改
- 数学公式：KaTeX 渲染行内 `$...$` 与块级 `$$...$$`
- Mermaid 图表：```mermaid 代码块渲染为流程图/时序图等
- 回车拆块、块首退格合并、列表自动续编号、Tab 缩进、Ctrl+B / Ctrl+I 加粗斜体
- 粘贴文本按块解析；粘贴图片自动存到 `assets/` 并插入引用

**界面**

- 无边框窗口，自绘标题栏（可拖动、双击最大化、支持 Aero Snap）
- 多标签页，切换时保留各自内容与滚动位置，未保存标签显示圆点
- 侧栏双面板：文件树（可打开文件夹）/ 文档大纲（点击跳转到对应标题）
- 四套主题：简约、夜间、纸张、日光，WPF 外壳与编辑器同步换色
- 状态栏：字数、行数、字符数，源码/所见即所得切换，当前主题与编码

**查找与导出**

- 查找替换浮层：高亮全部命中、上下跳转、单个/全部替换
- 导出 HTML（内联样式与字体，图片转绝对路径）
- 导出 PDF（WebView2 打印，自动去掉编辑区留白）
- 导出 Word `.docx`（手写 OOXML，不依赖 Office）

## 实现要点

- **外壳**：WPF（.NET 10），`WindowChrome` 自绘标题栏；单个 WebView2 承载整个编辑区，多标签复用同一实例
- **编辑引擎**：自研约 1300 行前端脚本。文档切成 block 数组，每块一个 `div.blk[data-type][data-state]`；输入时只改 `data-type` 预览字号，不重建 DOM，因此光标稳定；仅在块切换时重渲染
- **行内渲染**：先把转义字符、行内代码、公式、图片、链接抽成占位符 → 转义剩余纯文本 → 在纯文本上做强调替换 → 还原占位符，避免语法符号与 HTML 互相污染
- **图片路径**：WebView2 从虚拟主机 `app.local` 加载页面，`file://` 会被 CORS 拦截，因此自定义 `mw-img://local/<编码后的绝对路径>` 协议，由 C# 的 `WebResourceRequested` 直接回文件流
- **离线依赖**：KaTeX、highlight.js、Mermaid 全部下载到 `Resources/editor/vendor`，不联网也能用
- **导出**：HTML 内联 CSS 并改写字体与图片路径；PDF 走 `PrintToPdfAsync`；Word 用 `ZipArchive` 手写 `document.xml` / `styles.xml`

## 已验证

以下功能已在实机运行中逐项确认（不是"写完没跑过"）：

- 渲染：标题 1–4 级层级、粗/斜/粗斜/删除线/行内代码/链接、引用竖线、分割线、无序+有序+嵌套列表、表格边框与表头底灰、代码块语法高亮与语言标签、KaTeX 行内与块级公式、Mermaid 流程图、本地图片
- 块级双态：点击某块立即变等宽源码态；光标移到别处或点到块间空白，该块随即回到渲染态（分割线、表格这类点不进块内节点的块，点击时按块主动切入源码态，因此同样可编辑）
- 同一时刻只有当前块停留在源码态：快速连续点击不同块（含分割线、表格、图表这类主动切入的块）时，上一块会先被收回渲染态再切新块，不会出现两块同时停在源码态
- 点空白行：点在块与块之间的缝隙、正文两侧或内容下方的留白，光标落到该纵坐标处那一块（含末尾）并保持可见，不会把光标甩到文档末尾；点滚动条不动光标
- 拖动选择：按住鼠标拖动选文本时不会把块切进源码态，选区不会被重建打断；块只在单击（松开时判定未拖动）才进入源码态
- 复制源码：选中哪儿复制的就是那段 **markdown 源码**（标题带 `#`、引用带 `>`、列表带符号、强调带 `**`、表格带竖线、公式/图表带围栏），不做任何剥离，粘出去不会变形；唯一特例是选区完全落在一个代码框里时只复制代码正文（不含围栏），选区跨出代码框或全文复制时围栏一起复制
- 撤销/重做：`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；块结构重建会在原生撤销栈里留下不改内容的空步骤，这些空步骤被自动跳过，一次按键就是一次真实的内容变化
- 代码块编辑态（例外）：点进代码块**不会**切成 ` ``` ` 裸文本，代码框、底色、语言标签照旧，只有正文可以编辑；输入后光标离开，围栏再按 ` ```语言 ` 重建并恢复语法高亮，内容不丢；保存后文件里的语言标记同步更新
- 代码语言切换：代码块右下角常显语言标签（无语言时显示 `text`），点它弹出悬浮小输入框并预填当前语言，回车应用、Esc 取消；渲染态和编辑态下都能改，改完立即按新语言重新高亮
- 输入链路：新建文档粘贴 `# 标题` 与正文后立即渲染，状态栏字数/行数/字符数实时更新，标签显示未保存圆点
- 图片粘贴：剪贴板图片 → 落盘 `assets/img_yyyyMMdd_HHmmss_fff.png` → 插入 `![](assets/xxx.png)` → 经 `mw-img://` 协议正常显示
- 多标签：新建标签、文件树点击打开第二篇文档，各自内容互不干扰，切换后重新载入
- 侧栏：文件树打开文件夹后自动展开根节点并列出 md 文件；大纲面板按标题层级缩进列出并支持点击
- 查找替换浮层：`Ctrl+F` 正常弹出（查找框、上下跳转、替换框、全部替换）
- 主题：简约与夜间两套，窗口外壳、编辑区、代码高亮配色（hljs 明/暗主题）同步切换
- 导出 PDF：标题、两个代码块（带语言标签与高亮）、公式、Mermaid 图、表格排版均正确；**正在编辑（源码态）的块会在打印前自动刷回渲染态**，不会把裸 Markdown 打进 PDF
- 导出 Word：`document.xml` 含标题样式、表格 `w:tbl`、代码 Consolas 字体与粗体，6 个 OOXML 部件完整
- 导出 HTML：56KB 单文件，内联样式与 KaTeX，Mermaid 已固化为 `<svg>`，无 `mw-img://` 与相对字体路径残留
- 设置持久化：主题、窗口尺寸与位置、最近文件写入 `settings.json` 并在下次启动恢复


## 构建

```
dotnet build -c Release
```

需要 .NET 10 SDK。首次构建会自动还原 `Microsoft.Web.WebView2` 包。

## 已知限制

- 文档中连续多个空行会被归一为一个空行，因此保存后原文件的空行数量可能被压缩
- 表格直接在源码态编辑，不提供 Excel 式的单元格界面
- 撤销只覆盖当前块内的输入，跨块的结构性改动无法回退
- 大型文档（数万字以上）首次加载有明显延迟
- 「纸张」「日光」两套主题的色值已定义并接入同一套换色流程，但未在本次实机验证中逐一切换确认
- 查找替换浮层已确认能弹出与输入，命中高亮与跳转的视觉效果未逐项实测
- 图片粘贴落在哪个块取决于光标位置：若光标停在 `$$` 公式块内，插入的图片引用会被夹在公式内容里（这是光标位置问题，不是渲染 Bug）
